# Telegram Social Media Downloader Bot

Private, self-hosted Telegram bot: paste one supported TikTok, Instagram or X/Twitter post URL in a
private chat and receive the actual photos/videos with the original link underneath.

> Status: under construction. See `tasks.md` for the live checklist and `ops/dev-log.md` for what has
> actually been run and verified. Full documentation is completed in Phase 6 (T06.14).
